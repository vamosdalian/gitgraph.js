## A JavaScript library<br />to draw pretty git graphs.

<small>Use ⬅️ and ➡️ keys to navigate</small>

---

## Why this library? 🤔

- To draw git graphs examples that are <u>easy to maintain</u>
- For presentations, blog posts…
- … or any use case that implies to render a git graph!

---

## 📦 Install GitGraph.js

- For JS (<small>[README][js-readme]</small>): `npm i @vamosdalian/gitgraph-js`
- For React (<small>[README][react-readme]</small>): `npm i @vamosdalian/gitgraph-react`

[js-readme]: https://github.com/vamosdalian/gitgraph.js/tree/master/packages/gitgraph-js#gitgraphjs
[react-readme]: https://github.com/vamosdalian/gitgraph.js/tree/master/packages/gitgraph-react#gitgraphreact

---

### Importing the JS library

```html
<!-- Somewhere in the DOM -->
<div id="gitgraph"></div>
```

```js
import { createGitgraph } from "@vamosdalian/gitgraph-js";

const graphContainer = document.getElementById("gitgraph");
const gitgraph = createGitgraph(graphContainer);
```

---

### Importing the React library

```jsx
import { Gitgraph } from "@vamosdalian/gitgraph-react";

// Now you can use the component =>
<Gitgraph>{(gitgraph) => {}}</Gitgraph>;
```

## Advanced usage

---

You can customize the graph with `options`

```jsx
// @vamosdalian/gitgraph-js − Pass `options` as second param
const gitgraph = createGitgraph(graphContainer, options);
```

```jsx
// @vamosdalian/gitgraph-react − Provide `options` as props
<Gitgraph options={options}>{(gitgraph) => {}}</Gitgraph>
```

### `options.template`


## Create branch with `options`

```jsx
gitgraph.branch({
  name: "develop",
  style: {
    // Specific style for this branch
  },
});
```

---

## Create commit with `options`

```jsx
master.commit({
  subject: "Add feature",
  body: "More details about the feature…",
  dotText: "❤️",
  tag: "v1.2",
  style: {
    // Specific style for this commit
  },
});
```

---

## Merge branch with `options`

```jsx
master.merge({
  branch: develop,
  fastForward: true,
  commitOptions: {
    // Every valid `options` for a commit
  },
});
```

---

## Add event listeners on commits

```jsx
master.commit({
  subject: "Add tests",
  onMessageClick(commit) {
    alert(`Commit ${commit.hash} selected`);
  },
});
```

But also: `onMouseOver`, `onMouseOut`, etc.
